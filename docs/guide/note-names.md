# PAO Note Names

DiArMaqAr names every pitch class with the Persian-Arab-Ottoman (PAO) note names. The list below is the full set the app uses, one row per note, with its name in each of the four registers (Octave 0 to Octave 3), its IPN equivalent, and where the name comes from.

## Where the names come from

The names of Octave 1 and Octave 2 are compiled from Meshshāqa (1899:18), al-Khulaʿī (1904/2011:50–54, 77–78), al-Shawwā (1946:11–12), Allāh Wīrdī (1949:58, 153, 157, 177, 198, 203, 207), al-Ṣabbāgh (1954:47), al-Ḥilū (1961:69) and al-Rejab (2002:79–80). This compilation gives 36 note names per octave.

Most sources cover two octaves, from yegāh to saham/ramal tūtī. The lower register (Octave 0) uses the prefixes qarār and qarār qarār, and the upper register (Octave 3) uses jawāb and jawāb jawāb, following the convention found in Allāh Wīrdī (1949:203), al-Ḥilū (1961:70) and the four-octave list of Turkish makam equivalents in Arel (1968:1).

## Names added in DiArMaqAr

Four rows are not in the compiled sources. They were added because tanāghīm in the archive contain pitch classes that the compiled names cannot name without giving two different pitch classes the same name. Each follows the PAO convention that tīk raises a note and nīm lowers it.

- **tīk rāst** names pitch classes above rāst and below nīm zīrgūleh for the sake of al-Fārābī's tanāghīm (see al-Fārābī 950g, 950h) and the ʿushayrān-based version of al-Ṣabbāgh's tanghīm, where his own kurdī falls there (see al-Ṣabbāgh 1950).
- **tīk yegāh**, **tīk ʿushayrān** and **tīk dūgāh** name pitch classes just above yegāh, ʿushayrān and dūgāh (each below the next name in the list). They are needed in tanāghīm whose octaves are not exact, such as Ibn Sīnā (1037), where the strings added below the bamm sound these pitch classes in Octave 0 (see [Tanāghīm whose octaves are not exact](/guide/tuning-systems#tanaghim-whose-octaves-are-not-exact)).

With these additions the app uses 40 note names per octave. A name is added to this list only when a tanghīm in the archive uses it.
